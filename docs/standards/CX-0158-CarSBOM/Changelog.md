All notable changes to CX-0158 will be documented in this file.

## [1.1.0] - R26.09 (CX-Neptune)

### Added

- reference that all standards with nomenclature CX-0158-n must comply with this standard (CX-0158) in section 1.3 .
- SPDX format information in section 3.2.2.
- terminological denifition "SPDX Document", "Profile", and "Baseline Profile" in section 1.5.

### Changed

- structure in section 1.5.
- degree of obligation for the semantic model's unique identifier from "has the unique identifier" to "MUST use the unique identifier" in section 3.1.1.
- replaced allowed SPDX relationship with allowed SPDX profils in section 3.2.3.
- normative formulation for the policiy constraints referring to CX-0152 in section 5.8.

### Removed

- deprecated API standards in section 4.1.
- deprecated standards in section 6.1.

## [1.0.0] - R26.03 (CX-Titan)

### Added

- Initial version of Car SBOM Standard
